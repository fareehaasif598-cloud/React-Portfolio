# React Portfolio Capstone

Live Site: https://fareehaasif598-cloud.github.io/React-Portfolio/

This is my final React portfolio capstone, rebuilt from my Portfolio v1 using React components, routing, state, live GitHub data, and a controlled contact form.

## Tech Stack

- React
- Vite
- JavaScript
- React Router
- HTML
- CSS
- GitHub API
- GitHub Pages

## Features

- Component-based portfolio structure
- Project cards rendered from a data module
- Project filtering and search
- Dynamic project detail route using URL parameters
- GitHub repositories fetched live from my GitHub profile
- Loading, error, success, and empty states
- Controlled contact form with validation
- 404 page
- GitHub Pages deployment using HashRouter
